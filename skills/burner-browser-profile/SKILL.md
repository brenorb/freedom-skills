# Burner Browser Profile

Create a disposable task boundary; do not describe it as a complete anonymity
solution.

## Workflow

1. Define the task lifetime, sites, account boundary, downloads, and what must
   survive or be destroyed afterward.
2. Create a separate browser profile with sync disabled, no personal account,
   no unnecessary extensions, and a dedicated download directory.
3. Keep public and private sessions separate; do not paste secrets, import
   contacts, or reuse saved autofill/cookies across them.
4. Review downloads, site permissions, local storage, history, and extensions
   before closing. Remove the profile using the browser's supported method when
   the user confirms disposal.
5. Record the remaining network, device, and account-level linkability.

A separate profile does not hide IP addresses, browser fingerprinting, malware,
or identity revealed by login and content.

## Minimal check

Open the profile's settings and verify sync, extensions, permissions, and
download location before using it.
