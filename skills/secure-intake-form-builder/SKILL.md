# Secure Intake Form Builder

Collect what the organization can protect and use, not everything it could ask.

## Workflow

1. Define purpose, case owner, responder capacity, urgency categories, safe
   contact options, languages, accessibility, and threat model.
2. Make fields optional by default; avoid exact location, identity, device,
   political affiliation, or attachments unless necessary for the stated goal.
3. Write consent and confidentiality limits in plain language, including
   retention, deletion, withdrawal, and emergency escalation.
4. Define encryption/storage, access roles, routing, abuse handling, duplicate
   policy, and safe failure when the service is unavailable.
5. Test with synthetic data for leaks, required fields, confirmation messages,
   notifications, exports, and operator handoff before launch.

Never imply a web form is anonymous or secure without verifying its actual
hosting, logs, mail, analytics, and administrator access.

## Minimal check

The form has a data inventory, consent copy, retention rule, routing owner, and
synthetic-data test result.
