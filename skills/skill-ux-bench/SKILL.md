# Skill UX Bench

Measure comprehension and safe completion, not just agent task success.

## Workflow

1. Choose a realistic user task and define the audience, baseline knowledge,
   acceptable risk, and artifact that proves completion.
2. Compare no-skill and skill conditions with matched scenarios and no hidden
   coaching; use representative users or a clearly labeled expert proxy.
3. Record turns, clarification burden, comprehension of choices, warning
   recall, human-induced errors, confidence calibration, and completion.
4. Inspect whether warnings appeared before the risky decision and whether the
   language preserved user agency without jargon or false certainty.
5. Revise only the observed failure and repeat on a held-out scenario.

Do not optimize for shorter conversations if that hides a needed decision.

## Minimal check

The evaluation includes a comprehension question about the task's main privacy
or recovery tradeoff.
