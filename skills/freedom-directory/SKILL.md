# Freedom Directory

Turn a loose list of services into a small directory that another person can
use without guessing what each entry means.

## Workflow

1. Define the user goal and geography before collecting entries; avoid
   publishing a global list when a local one is enough.
2. For each entry record name, category, purpose, official URL, access method,
   last checked time, operator/ownership if known, and privacy caveats.
3. Verify links and distinguish official endpoints, community mirrors, and
   unverified suggestions. Keep hidden-service addresses opt-in.
4. Add a fallback or offline reference where one exists, and flag single points
   of failure rather than hiding them.
5. Export Markdown or JSON only after checking duplicates, stale links, and
   accidental secrets or private contacts.

Never imply that inclusion is endorsement, availability, safety, or legal
approval. Do not publish private relay addresses without explicit permission.

## Minimal check

Run a link/duplicate review and ensure every entry has a purpose, source, and
last-checked date.
