# Account Compartment Builder

Reduce accidental cross-linking by designing boundaries before creating more
accounts.

## Workflow

1. List roles and consequences of linkage: personal, public advocacy, source
   contact, finance, admin, and recovery.
2. For each compartment define identifier, email/phone, browser/device,
   password manager entry, 2FA, recovery contact, payment method, and allowed
   integrations.
3. Mark shared infrastructure that can still correlate compartments: IP,
   device fingerprint, phone number, timing, writing style, contacts, or cloud
   sync.
4. Create only the minimum accounts, use unique credentials, and document the
   migration/offboarding path without placing secrets in the plan.
5. Review the map before linking profiles, importing contacts, or enabling
   cross-account recovery.

Compartmentalization is risk reduction, not guaranteed anonymity. Do not use
it to conceal unauthorized access or impersonation.

## Minimal check

Each compartment has an owner, purpose, recovery path, and explicit list of
prohibited links.
