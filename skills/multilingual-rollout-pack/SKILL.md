# Multilingual Rollout Pack

Translate the decision and safety boundary, not just the words.

## Workflow

1. Define audiences, languages, literacy/accessibility needs, deadlines,
   trusted reviewers, and which terms must remain technically exact.
2. Create a source glossary for privacy, consent, custody, recovery, urgency,
   and stop conditions; distinguish literal text from culturally adapted copy.
3. Produce short and long versions, offline/low-bandwidth copies, examples,
   screenshots, and a way to report translation problems safely.
4. Have fluent domain reviewers check negation, warnings, names, dates, consent,
   and instructions before publication.
5. Version each language, publish corrections consistently, and record which
   languages are incomplete rather than implying parity.

Do not machine-translate high-stakes legal, medical, or safety instructions
without qualified review.

## Minimal check

The rollout includes a reviewed glossary, a warning/consent review, version
mapping between languages, and a correction owner.
