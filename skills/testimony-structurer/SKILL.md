# Testimony Structurer

Make a testimony easier to review without silently turning recollection into
verified fact.

## Workflow

1. Preserve the original statement and create a derivative outline with a
   stable reference to its source.
2. Separate direct observation, quoted speech, inference, hearsay, memory gap,
   and later-added context.
3. Organize events by time and place; retain approximate wording and mark
   conflicts rather than harmonizing them.
4. Link each assertion to the relevant recording, document, image, or follow-up
   question. Minimize unnecessary personal identifiers.
5. Return the outline for speaker or authorized reviewer correction before it is
   used publicly or as a factual finding.

Do not rewrite testimony into polished advocacy copy without clearly labeling
the transformation.

## Minimal check

Every material assertion has a source pointer and an uncertainty label.
