# White Noise connector

Chat with an agent runtime you already run (Hermes, OpenClaw, Claude Code, Codex, OpenCode, Pi or Goose) from White Noise, over end-to-end encrypted Marmot groups. The connectors are maintained upstream in [marmot-protocol/mdk](https://github.com/marmot-protocol/mdk/tree/master/integrations); this folder holds only the prompt.

Paste [`PROMPT.md`](PROMPT.md) into the agent on the machine that will run the connector. Upstream docs last checked 2026-11-13 (`mdk` `3c8616b`).
