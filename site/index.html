How it works

  1. You ask in plain words

    Send the signed PDF to Ana on Signal.

  2. Your agent picks the tested skill

    It follows that skill’s workflow and uses the real tool.

  3. It shows the caveats and asks first

    Nothing is sent, paid or published until you say yes.

    Install

    1. All skills Recommended

      With the open skills CLI.

      npx skills add brenorb/freedom-skills

    2. One skill

      Add -s and the skill’s name.

      npx skills add brenorb/freedom-skills -s signal-cli

    3. By hand

      A skill is a folder. Copy it where your agent looks.

      git clone https://github.com/brenorb/freedom-skills
cp -r freedom-skills/skills/signal-cli ~/.claude/skills/

    It asks before it acts.

    • Confirms first. Skills tell your agent to show the caveats and get your OK before it sends, pays or publishes.
    • Plain text you can read. Read any skill before you install it, or scan it first with SkillSpector.
    • Personal data stays out of the model. Rampart hooks redact selected details before a request reaches the model and restore them in the reply.
    • Your keys, your money. The agent wallet is self-custodial.

    Why

    Freedom shouldn’t require 10,000 hours of training.

    Freedom tools let people talk, pay and publish without asking permission, but each comes with its own setup and security homework. Freedom Skills turns that know-how into tested skills your agent can follow.
